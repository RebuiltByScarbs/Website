How it actually works

The Comeback Process.

Four stages. Not a straight line — but always in this order.

01

Audit

Training history, injury history, current capacity, and the actual reason the last comeback attempt stalled. No program gets written before this.

02

Rebuild the foundations

Volume and intensity brought back up deliberately, nutrition habits reset, technique refined, and anything still healing worked around — so the next 12 months don't get derailed by week three.

03

Load it back on

Progressive overload returns properly, nutrition dialled to the goal, and a setback protocol already in place before you need it — not after.

04

Make it boring

The goal is a routine you don't have to think about any more, with safeguards already built in for the next time life gets in the way. This is where coaching gets quieter and you start running it yourself.
